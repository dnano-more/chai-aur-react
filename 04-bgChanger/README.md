# Background Changer

In this project, we have created a simple background color changer using React and Tailwind CSS. The application allows users to change the background color of the page by clicking on buttons that represent different colors.

What i learned from this project is how to use the `useState` hook to manage state in a React component, and how to use the `onClick` event handler to update that state based on user interactions. This allows us to create dynamic and interactive applications that respond to user input.

## Technologies Used

- React
- Tailwind CSS
